【笔记，第 2 页】可辨认的结构包括：

- **对象内部**：经济、政治、文化、社会结构；要素及其结构；社会矛盾、阶级状况。

### 5. 两条唯物史观基础认识

【笔记，第 3 页】

1. 物质生产是社会生活的基础。
2. 人民群众是历史的创造者。

【补充理解】前者提醒我们分析生产条件、生产关系及其变化；后者提醒我们关注广大人民群众的实践作用。落到本节近代史内容，就是既看土地、资本等生产资料及其占有关系，也看农民、工人等群体的处境和行动。

不能把社会发展只解释为少数人物的个人意志，也不能把经济作用理解为对一切政治文化现象的机械、直接决定。

### 6. 重点辨析：“第二次结合”与“第二个结合”

【笔记，第 3 页】两种提法相邻出现，复习时必须分开。

## 二、后半段起点：认识封建社会，要看生产关系

来源：PDF 第 3 页下半；转写 `00:00:02` 段。

### 1. 为什么老师反复讲“生产资料在谁手里”

【课堂】分析社会时，不能只看表面现象，要看生产资料由谁占有，不同人怎样参与生产、获取生活资料。

| 内容 | 课堂涉及的例子 | 应当抓住的概念 |
| --- | --- | --- |
| 生产资料 | 土地、机器设备、工厂等 | 用于生产活动的物质条件 |
| 生活资料 | 个人日常消费所需物品 | 满足生活消费的资料，不能与生产资料混同 |
| 封建生产关系 | 地主占有大量土地，农民依赖土地生产 | 地主土地所有制及对农民的剥削 |
| 资本主义生产关系 | 资本家占有生产资料，工人受雇劳动 | 资本与雇佣劳动的关系 |

【校正】转写用“给地主干活、领取报酬”作统一解释，容易把不同关系混在一起。**佃农租种地主土地并缴纳地租，与工人受雇领取工资不是同一关系**；长工等雇佣形式也不能概括全部封建剥削关系。

【笔记】“共产主义，共生产资料”是理解线索。可用来提醒自己关注生产资料所有制，不能理解成“把所有个人日用品拿出来平均分”，也不能由此推出收入在任何阶段都完全相同。

### 2. 中国封建社会的几个观察维度

| 维度 | 整理要点 |
| --- | --- |
| 经济 | 地主土地所有制；以家庭为单位的小农经济；农业与家庭手工业相结合；自然经济占主要地位 |
| 政治 | 高度中央集权的封建君主专制制度 |
| 文化 | 儒家思想在传统社会思想文化中占主导地位，同时存在其他思想传统 |
| 社会结构 | 宗法等级关系；家族、族权与政治权力之间存在联系 |

**三个易错点：**

- 自然经济占主要地位，不等于没有商品交换、商人、货币和借贷。
- 本课社会形态意义上的“封建”，不能直接等同于周代“分封诸侯”的制度。
- 中央集权主要讨论**中央与地方的权力关系**；君主专制主要讨论**君主权力及其与臣僚的关系**。不能用“是否凡事由皇帝一个人决定”来定义中央集权。

### 3. 从了解国情到分析问题

【课堂】老师用“检查身体—读取数据—判断疾病”类比调查研究：收集数据之后，还要识别背后的问题及其关系。

复习时可以写成：

> 调查研究 → 把握基本国情 → 分析社会性质和主要矛盾 → 确定任务与解决路径。

【校正】基本国情是一个综合概念，不能只用“基本矛盾”四个字代替；“社会基本矛盾”和某一历史阶段的“社会主要矛盾”也不相同，见第六部分。

## 三、近代中国为什么是半殖民地半封建社会

来源：PDF 第 3—4 页；转写 `00:15:55` 至 `00:36:09` 附近。

### 1. 核心结论

**近代中国的基本国情是半殖民地半封建的社会性质，这是认识近代中国社会问题和革命问题最基本的依据。**

【笔记】用“1840—1949”标记近代中国。这是便于复习的时期范围；【补充】其社会性质的形成和加深是历史过程，不应理解为 1840 年一瞬间全部完成。

### 2. 两个“半”分别说明什么

| 比较项 | 半殖民地 | 半封建 |
| --- | --- | --- |
| 主要观察角度 | 国家的独立、主权及其受到的控制 | 社会经济结构、生产关系的变化 |
| 原有状态 | 独立的国家 | 封建社会 |
| 发生的变化 | 列强侵略破坏主权，中国丧失了完全独立的地位 | 自然经济受冲击，资本主义生产关系出现并发展 |
| 仍然保留什么 | 独立国家和政府的名义，尚未被整体变成完全殖民地 | 封建剥削关系仍然存在并占重要支配地位 |
| 不能怎样理解 | 不是领土恰好被占去一半 | 不是封建经济恰好占 50% |

**最短记法：半殖民地看主权；半封建看生产关系。**两个角度相互联系，不能把一个概念的解释拿来回答另一个概念。

### 3. “半殖民地”的形成及未完全殖民化的原因

【课堂】列强通过侵略及不平等安排，损害中国领土、关税、司法等方面的主权，并控制经济命脉、影响政治。中国仍保留国家和政府的形式，因此不是全国整体都直接变成某一个列强的殖民地。

没有被完全殖民化，课堂强调两个方面：

1. 中国人民持续反抗。
2. 列强之间争夺和牵制，难以由某一国独占中国。

国土广阔等条件可以辅助理解，但不能替代上述分析。租界只是主权受损的一类表现；**半殖民地不是单纯按租界或被占领地区的面积计算。**

### 4. “半封建”为什么既有变化，又保留旧关系

【课堂整理】

> 外国资本主义侵入、商品输入和经济渗透
> → 自给自足的自然经济及部分手工业受到冲击
> → 一部分农民、手工业者破产，转向城市谋生
> → 资本主义生产关系和新的阶级力量发展
> → 但封建关系并未退出支配地位，民族资本主义也未成为主要经济形式。

要同时记住两面：

- **变了**：中国已不是原来那种相对封闭的封建社会。
- **未彻底改变**：中国没有由此发展成为独立的资本主义国家。

【校正】“西方思想传进来，所以变成半封建”只能描述一部分伴随现象。回答社会性质问题，要落实到**经济基础、生产关系和封建剥削关系是否仍然存在**，不能只谈文化风气。

### 5. 为什么民族资本主义没有成为主要形式

【课堂】外有资本帝国主义压迫，内有封建势力束缚；民族资本主义虽有发展，但力量弱小，与外国资本及国内封建势力存在复杂联系，难以独立成长为支配社会经济的力量。

理解关键：**资本主义因素出现，不等于整个社会已经成为资本主义社会。**

### 6. 课堂选择题：怎样判断“半封建”

转写称这是一道“2024 年考研题”，但没有完整原题和题号。以下仅按转写恢复选项意思，不作为已核实的真题逐字版本。

| 选项意思 | 判断 | 原因 |
| --- | --- | --- |
| 封建经济占整个经济的一半 | 错 | “半”不是数量比例 |
| 中国出现了资本主义生产关系 | 按课堂题意应选 | 抓住了原有封建社会发生变化的经济表现 |
| 中国完全丧失独立地位 | 错 | “完全”不符合半殖民地的含义，而且这在讨论主权 |
| 封建剥削制度的根基彻底动摇 | 错 | 封建关系并未被彻底消除，仍有重要支配作用 |

答题时先找题干限定词：问的是“半封建”，还是“半殖民地”？再警惕“一半”“完全”“彻底”等词。

## 四、六个基本特征：把六条记成一条分析链

来源：PDF 第 4 页“六个特征、内在关系”；转写 `00:36:09` 至 `00:58:23` 附近。

以下按**课堂排列顺序**归纳，属于整理概述，不是教材或毛泽东著作的逐字引文。

| 序号 | 基本特征 | 提示词 | 对理解社会的作用 |
| --- | --- | --- | --- |
| 1 | 资本帝国主义逐步操纵中国的财政、经济命脉和政治，成为支配中国的重要决定性力量 | 外来控制 | 解释民族独立为什么是迫切问题 |
| 2 | 本国封建势力同外国侵略势力相勾结，成为压迫中国人民的社会基础和支柱 | 内外勾结 | 解释反帝与反封建为什么相互联系 |
| 3 | 自然经济遭破坏，但封建地主土地所有制及对农民的剥削仍然保持，并与其他剥削形式结合 | 旧关系仍在 | 说明“半封建”没有等于封建关系消失 |
| 4 | 民族资本主义有所发展，但发展缓慢、力量软弱，未成为社会经济的主要形式 | 新力量弱小 | 说明资本主义发展受到限制 |
| 5 | 各地区经济、政治、文化发展极不平衡，地方割据等现象突出 | 发展不平衡 | 为理解革命力量为何能在部分地区发展提供条件分析 |
| 6 | 人民在帝国主义、封建主义等压迫下生活困苦，广大农民处境尤其困难 | 人民受压迫 | 说明革命的社会根源和群众基础 |

### 1. 老师强调的记忆关系

> **1＋2：谁在支配？**外来势力与本国封建势力。
>
> **3＋4：经济结构怎样？**旧关系顽固，新力量弱小。
>
> **5：各地是否一样？**发展极不平衡。
>
> **6：最终落到谁身上？**广大人民承受压迫和贫困。

压缩成一句：**外来控制、封建勾结；旧制仍存、新资弱小；发展不均、人民困苦。**

### 2. 为什么能由这些特征联系到革命道路

【课堂分析】

| 国情特点 | 可以联系到的认识 |
| --- | --- |
| 广大农民受压迫，具有改变处境的要求 | 革命必须重视农民及农村的群众基础 |
| 各地发展不平衡，统治力量分布不均 | 革命力量可寻找统治相对薄弱的地区开展斗争 |
| 民族资产阶级受压迫，又有依赖和妥协的一面 | 需要具体分析同盟关系，不能笼统处理 |
| 帝国主义与封建势力相互勾结 | 反帝与反封建任务紧密关联 |

【边界】这些联系帮助理解农村革命根据地、农村包围城市等道路的国情依据，**不是这条道路形成和发展的全部条件**。党的领导、群众基础、武装斗争等还需要结合后续课程学习。

【校正】老师把前两条概括为“上层建筑”、第三四条概括为“经济基础”，适合辅助记忆，但不要机械划界：第一条本身也涉及经济控制。叙述从政治讲到经济，也不表示理论上是“上层建筑单向决定经济基础”。

## 五、阶级关系变化与统一战线

来源：PDF 第 4 页；转写 `00:58:23` 至文末。

### 1. 阶级关系怎样变化

| 阶级或群体 | 课堂涉及的变化与处境 | 复习抓手 |
| --- | --- | --- |
| 地主阶级 | 部分地主进入城市经营工商业；地主与商人、官僚等群体之间可能相互转化 | 阶级来源和现实利益关系要结合起来看 |
| 农民阶级 | 部分农民破产，失去或缺少土地；部分进入城市成为产业工人的来源 | 人数多、受压迫深，是重要群众基础 |
| 工人阶级 | 随近代工业发展而成长，集中劳动有利于组织和联系，受到多重压迫 | 理解其组织性、革命性；不能只以人数多少衡量作用 |
| 官僚买办资产阶级 | 与政治特权、外国资本及封建势力联系紧密 | 不能与民族资产阶级混为一谈 |
| 民族资产阶级 | 受帝国主义和封建势力压迫，同时又同其存在联系，力量较弱 | 革命性与软弱性、妥协性并存 |

【补充定位】在新民主主义革命的理论框架中，**无产阶级是领导力量，农民是主力军，中国共产党是领导核心**。三种说法回答不同问题，不能互换。

“农民是主力军”不等于“农民阶级能够独立领导革命”；“工人阶级人数相对少”也不能直接推出其不能发挥领导作用。

### 2. 民族资产阶级的两面性

【课堂】可以沿两条线理解：

- **受压迫的一面**：民族经济发展受限制，因而有反帝反封建的要求。
- **有联系、力量弱的一面**：经济和社会联系使其容易动摇、妥协。

所以，分析民族资产阶级，既不能说它“始终彻底革命”，也不能说它“完全没有革命性”。具体态度还要看历史阶段和现实条件。

### 3. 统一战线为什么需要阶级分析

【课堂】先分析各阶级的经济地位、利益、与其他力量的关系，再辨别革命对象、依靠力量和可以争取的同盟力量。

老师用“朋友多、敌人少”作通俗解释。正式答题应落到**团结可以团结的力量、扩大革命力量、处理不同阶级之间的关系**，不能把统一战线简单等同于私人交友或职场结盟。

【补充】统一战线、武装斗争、党的建设，是新民主主义革命的三大法宝。现有转写重点在统一战线，另两项不在此稿中展开。

## 六、两对主要矛盾：先分层次，再记顺序

来源：PDF 第 3—4 页；转写 `00:46:57` 附近及末段。

### 1. 近代中国的两对主要矛盾

| 主要矛盾 | 理解角度 | 联系的革命任务 |
| --- | --- | --- |
| 帝国主义和中华民族的矛盾 | 民族矛盾 | 反对帝国主义侵略、争取民族独立 |
| 封建主义和人民大众的矛盾 | 阶级矛盾 | 反对封建压迫、争取人民解放 |

**其中，帝国主义和中华民族的矛盾，是近代中国各种矛盾中最主要的矛盾。**

同时保留老师在 `00:46:57` 段指出的限定：不同历史时期、具体条件下，矛盾的地位及表现会变化。不能把整体判断理解成每一个时期都完全相同。

### 2. 为什么两个任务不能割裂

【课堂整理】帝国主义通过本国封建势力加强统治，本国封建势力又依靠外来力量维持地位。因此，反帝与反封建相互联系，革命既要解决民族独立问题，也要解决人民解放问题。

“封建主义和人民大众”不能在所有题目中简单缩写成“地主和农民”；地主与农民的对立是其重要体现，但不穷尽完整概念。

### 3. 四组容易混淆的词

| 概念 | 应回答什么 | 本课应用或辨析 |
| --- | --- | --- |
| 社会基本矛盾 | 社会运行中根本的矛盾关系是什么？ | 【补充】生产力与生产关系、经济基础与上层建筑的矛盾 |
| 某一历史时期的社会主要矛盾 | 这一阶段哪些矛盾处于主要地位？ | 近代中国的两对主要矛盾 |
| 主要矛盾与次要矛盾 | 多种矛盾中，哪种起主导作用？ | 不等于简单按“新出现／原来就有”排序 |
| 内部矛盾与外部矛盾 | 相对于所分析的对象，矛盾位于何种关系中？ | 必须先明确对象边界；不能认定“外部一定主要、内部一定次要” |

【补充辨析】“主要矛盾”是在多个矛盾之间比较；“矛盾的主要方面”是在同一个矛盾的双方之间比较。二者不是同一概念。

### 4. 与新时代主要矛盾对照记忆

【笔记，第 3 页】把毛泽东对近代社会的分析与“十九大、矛盾分析、新时代”并置。下表补齐其规范内容。

| 时期 | 对应表述 |
| --- | --- |
| 近代中国 | 帝国主义和中华民族、封建主义和人民大众的矛盾 |
| 中国特色社会主义新时代 | 人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾 |

新时代这一表述见[党的十九大报告](https://gzw.beijing.gov.cn/gzdj/xxyd/sjdbg/)。这里的联系是**根据具体时代条件分析具体问题**，不是把不同时期的矛盾混用。

## 七、课堂延伸：依法治国与以德治国

来源：转写 `00:00:02` 段及 `00:15:55` 后的相关内容。

【课堂要点】坚持依法治国和以德治国相结合。

【补充理解】法律通过制度规范和国家强制力发挥作用，道德通过价值引导、行为评价和社会认同发挥作用，二者相互配合。此处的规范表述可核对[《习近平新时代中国特色社会主义思想学习纲要》相关内容](https://www.12371.cn/2019/08/01/ARTI1564615298016193.shtml)。

**不要把课堂例子直接写成结论：**

- 古代有律法，不等于古代已经具备现代意义的法治。
- 囚徒困境例子用于提示个体选择与集体结果可能不一致，不能直接推出“法治必然使一切社会利益最大化”。
- 以德治国不能解释为“道德评价可以替代法律程序”。

## 八、简答与论述：可直接用于练习的提纲

以下为根据材料整理的答题框架，不是真题答案或命题预测。

### 1. 如何理解近代中国的半殖民地半封建社会性质？

**定义分开写，最后说明联系。**

第一，在资本帝国主义侵略下，中国主权遭到严重破坏，丧失完全独立地位，但仍维持国家和政府的名义，因此具有半殖民地性质。

第二，外国资本主义侵入使自然经济逐渐解体，资本主义生产关系有所发展，但封建剥削关系仍然存在并占重要支配地位，民族资本主义未成为主要经济形式，因此具有半封建性质。

第三，两者相互联系，共同构成近代中国的基本国情，并成为认识社会矛盾和革命问题的基本依据。

### 2. 如何理解六个基本特征的内在联系？

**按“统治力量—经济结构—发展状况—人民处境”组织。**

外来侵略势力与本国封建势力相勾结，构成统治与压迫的重要力量。经济上，自然经济受破坏而封建关系仍然保持，民族资本主义有所发展却力量软弱。各地区经济政治文化发展极不平衡，广大人民生活困苦。这些特征相互作用，共同说明近代中国的社会性质及革命的社会根源。

需要展开时，再分别说明其与反帝反封建、农民群众基础、革命道路选择的联系。

### 3. 为什么必须重视农民，又不能把农民主力军等同于领导力量？

**先讲处境与数量，再区分作用。**

广大农民受压迫深、具有改变现状的要求，是革命的重要群众基础和主力军。但主力军与领导力量不是同一概念，不能仅凭人数或受压迫程度判断领导作用。在新民主主义革命理论中，领导力量是无产阶级，领导核心是中国共产党。

### 4. 民族资产阶级为什么具有两面性？

**一方面受压迫，另一方面有依赖和联系。**

民族资产阶级受到帝国主义和封建势力压迫，具有反帝反封建的要求；但自身经济力量薄弱，又与这些势力存在一定联系，容易表现出软弱和妥协。因此，必须结合具体历史条件分析其政治态度，不能作单一、绝对判断。

### 5. 近代中国的主要矛盾及其相互关系是什么？

**两对矛盾—最主要矛盾—内外勾结—两项任务。**

近代中国的主要矛盾是帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾，其中前者是最主要的矛盾。由于帝国主义和本国封建势力相互勾结，反帝与反封建相互联系，争取民族独立和人民解放成为相互关联的任务。分析具体历史阶段时，还应注意矛盾地位和表现的变化。

## 九、复习速记与自测

### 1. 一页式速记

| 题眼 | 第一反应 |
| --- | --- |
| 认识近代中国问题的基本依据 | 半殖民地半封建的社会性质／基本国情 |
| 半殖民地 | 主权受损，丧失完全独立地位，但并非整体完全殖民地 |
| 半封建 | 新的资本主义关系出现，旧的封建关系仍然保持 |
| 六个特征 | 外来控制、封建勾结、旧制仍存、新资弱小、发展不均、人民困苦 |
| 六条之间的关系 | 谁支配 → 经济结构 → 发展状况 → 人民处境 |
| 两对主要矛盾 | 帝国主义／中华民族；封建主义／人民大众 |
| 最主要矛盾 | 帝国主义和中华民族的矛盾 |
| 农民、无产阶级、共产党 | 主力军、领导力量、领导核心 |
| 民族资产阶级 | 革命性与软弱性、妥协性并存 |

| 三个历史决议 | 1945、1981、2021 |

### 2. 先遮住答案做自测

1. “半封建”中的“半”能否理解成经济比例？为什么？
2. 中国出现资本主义生产关系，是否就意味着成为独立资本主义国家？
3. 租界的存在能否完整解释半殖民地性质？
4. 没有完全殖民化，课堂强调哪两个原因？
5. 用四个问题把六个特征串起来。
6. 农民是主力军与无产阶级是领导力量，有没有矛盾？
7. 民族资产阶级的革命性和妥协性分别从哪里来？
8. 写出近代中国两对主要矛盾，圈出最主要的一对。
9. “社会基本矛盾”与“近代中国主要矛盾”能不能互换？
10. “外部矛盾总是主要矛盾”是否正确？
11. “第二次结合”与“第二个结合”各指什么？
12. 写出三个历史决议的年份及对应会议。

### 3. 答案要点

1. 不能；它描述社会经济结构与生产关系的变化，不是 50% 的比例。
2. 不意味着；民族资本主义仍弱小，封建关系与外来控制仍然存在。
3. 不能；还包括更广泛的主权受损、经济及政治控制。
4. 中国人民的反抗；列强之间的争夺和牵制。
5. 谁在支配？经济结构怎样？各地是否一样？人民处境如何？
6. 没有；两者回答不同问题，人数多不自动等于领导力量。
7. 受压迫产生反抗要求；力量弱小及同旧势力的联系带来妥协性。
8. 帝国主义和中华民族；封建主义和人民大众。前者最主要。
9. 不能；前者是一般社会理论概念，后者针对特定历史条件。
10. 错；必须分析具体条件，内外划分与主次划分不是一回事。
11. 第二次结合：探索适合中国的社会主义建设道路；第二个结合：同中华优秀传统文化相结合。
12. 1945 六届七中；1981 十一届六中；2021 十九届六中。

### 2. 一处明确的史实性纠正

转写提到“印度的国家元首是英国君主”，这一说法不正确。**印度是共和国，国家元首为总统。**不能因为一个国家具有英联邦背景，就认定英国君主是其国家元首。核对来源：[外交部印度国家概况](https://www.fmprc.gov.cn/web//gjhdq_676201/gj_676203/yz_676205/1206_677220/1206x0_677222/)。
