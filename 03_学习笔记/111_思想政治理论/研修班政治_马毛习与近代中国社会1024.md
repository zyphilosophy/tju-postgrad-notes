# 研修班政治：马毛习与近代中国社会

## 一、整体知识框架

贯穿各部分的分析主线是：

> 理论方法 → 具体国情 → 社会结构 → 主要矛盾 → 实践任务与实现路径。

| 理论与历史内容 | 理解重点 |
| --- | --- |
| 马克思主义基本立场、观点、方法 | 认识社会、生产、阶级、矛盾和人的实践 |
| 马克思主义中国化时代化 | 把基本原理同中国具体实际和时代条件结合起来 |
| 毛泽东思想相关内容 | 认识近代中国社会，分析革命对象、动力、领导力量与道路 |
| 习近平新时代中国特色社会主义思想相关内容 | 把握新时代的历史方位、主要矛盾和发展任务 |
| 中国近现代史 | 理解理论与实践形成、发展的历史条件 |

### 1. 系统分析的几个维度

- **内部结构**：经济、政治、文化、社会结构，各要素及其相互关系。
- **外部环境**：国际格局及其变化。
- **时间维度**：历史基础、现实状况和未来发展。
- **问题分析**：社会矛盾、阶级状况及制约发展的因素。
- **目标与路径**：明确发展目标，分析实现目标需要解决的问题。

事实判断侧重说明现实状况，价值判断侧重评价与目标。二者相互联系，但不能以价值愿望代替对现实条件的分析。

目标导向与问题导向相互配合：明确目标，识别制约因素，提出解决路径。

### 2. 两个大局与五位一体

| 概念 | 基本内容 | 理解重点 |
| --- | --- | --- |
| 两个大局 | 中华民族伟大复兴的战略全局；世界百年未有之大变局 | 统筹国内发展与国际环境 |
| 五位一体总体布局 | 经济建设、政治建设、文化建设、社会建设、生态文明建设 | 从相互联系的五个方面推进中国特色社会主义事业 |

## 二、唯物史观与马克思主义中国化时代化

### 1. 两条基础认识

**物质生产是社会生活的基础。**分析社会，应当关注生产条件、生产关系及其变化。

**人民群众是历史的创造者。**认识社会发展，应当关注广大人民群众的实践作用。

这两条认识要求把物质条件与人的实践结合起来，不能把历史变化只归结为少数人物的意志，也不能把经济作用理解为对政治、文化现象的机械决定。

### 2. “第二次结合”与“第二个结合”

| 提法 | 含义 | 记忆重点 |
| --- | --- | --- |
| 毛泽东提出的“第二次结合” | 在社会主义革命和建设条件下，把马克思列宁主义基本原理同中国具体实际结合，探索适合中国的社会主义建设道路 | 探索建设道路 |
| “两个结合”中的第一个结合 | 把马克思主义基本原理同中国具体实际相结合 | 中国具体实际 |
| “两个结合”中的第二个结合 | 把马克思主义基本原理同中华优秀传统文化相结合 | 中华优秀传统文化 |

“第二次结合”对应 1956 年前后探索中国社会主义建设道路的历史背景；“第二个结合”强调马克思主义基本原理与中华优秀传统文化的结合。两者不能混用。参考：[党史百问](https://www.12371.cn/2022/07/22/ARTI1658479518501769.shtml)、[在文化传承发展座谈会上的讲话](https://www.moe.gov.cn/jyb_xwfb/moe_176/202308/t20230831_1077496.html)。

## 三、生产关系与中国封建社会

### 1. 生产资料与生活资料

| 概念 | 基本含义 |
| --- | --- |
| 生产资料 | 用于生产活动的物质资料，包括劳动资料与劳动对象 |
| 生活资料 | 用于满足人们生活消费需要的资料 |
| 生产资料所有制 | 人们对生产资料的占有关系，是认识生产关系的重要方面 |

分析社会性质，需要考察生产资料由谁占有、人们以什么关系参与生产，以及产品如何分配。

理解共产主义中的生产资料公有，不能将其等同于把所有个人生活用品拿来平均分配，也不能据此推出任何阶段的个人收入都完全相同。

### 2. 封建生产关系与资本主义生产关系

| 比较项 | 封建生产关系 | 资本主义生产关系 |
| --- | --- | --- |
| 生产资料占有 | 地主占有大量土地 | 资本家占有生产资料 |
| 主要关系 | 地主与农民之间的关系 | 资本与雇佣劳动之间的关系 |
| 需要注意的区别 | 佃农租种地主土地并缴纳地租 | 工人受雇劳动并领取工资 |

租佃关系与雇佣关系不能混为一谈。长工等雇佣形式也不能概括全部封建剥削关系。

### 3. 中国封建社会的主要特点

| 维度 | 主要特点 |
| --- | --- |
| 经济 | 地主土地所有制；以家庭为单位的小农经济；农业与家庭手工业相结合；自然经济占主要地位 |
| 政治 | 高度中央集权的封建君主专制制度 |
| 文化 | 儒家思想占主导地位，同时存在其他思想传统 |
| 社会结构 | 宗法等级关系；家族、族权与政治权力相联系 |

自然经济占主要地位，不等于没有商品交换、商人、货币和借贷。社会形态意义上的“封建”，也不能直接等同于周代“分封诸侯”的制度。

**中央集权与君主专制的区别：**

- 中央集权主要涉及中央与地方的权力关系。
- 君主专制主要涉及君主权力及其与臣僚的关系。

### 4. 从国情出发分析社会

> 调查研究 → 把握基本国情 → 分析社会性质和主要矛盾 → 确定任务与解决路径。

基本国情是综合性的概念，不能仅用“基本矛盾”代替。社会基本矛盾与某一历史阶段的社会主要矛盾，也属于不同层次的概念。

## 四、近代中国的社会性质

### 1. 基本国情

**近代中国的基本国情是半殖民地半封建的社会性质，这是认识近代中国社会问题和革命问题最基本的依据。**

中国近代史通常以 1840—1949 年为时期范围。半殖民地半封建社会的形成和加深是一个历史过程，并非在 1840 年一瞬间全部完成。

### 2. 两个“半”的含义

| 比较项 | 半殖民地 | 半封建 |
| --- | --- | --- |
| 主要角度 | 国家独立、主权及其受到的控制 | 社会经济结构和生产关系 |
| 原有状态 | 独立的国家 | 封建社会 |
| 发生的变化 | 列强侵略破坏主权，中国丧失完全独立的地位 | 自然经济受到冲击，资本主义生产关系出现并发展 |
| 仍然保留的部分 | 独立国家和政府的名义，未整体沦为完全殖民地 | 封建剥削关系仍然存在并占重要支配地位 |
| 概念辨析 | 不是领土恰好被占去一半 | 不是封建经济恰好占一半 |

记忆要点：**半殖民地看主权，半封建看生产关系。**两个方面相互联系，共同构成近代中国的社会性质。

### 3. 半殖民地的形成

资本帝国主义通过侵略和不平等安排，损害中国领土、关税、司法等方面的主权，并控制经济命脉、影响政治。中国丧失了完全独立的地位，但仍保留国家和政府的形式。

中国没有被完全殖民化的重要原因包括：

1. 中国人民持续反抗。
2. 列强之间争夺和牵制，难以由某一国独占中国。

半殖民地性质不能单纯按租界或被占领地区的面积来判断，还要考察主权、经济和政治受到控制的程度。

### 4. 半封建的形成

> 外国资本主义侵入、商品输入和经济渗透
> → 自给自足的自然经济及部分手工业受到冲击
> → 一部分农民、手工业者破产并转向城市谋生
> → 资本主义生产关系和新的阶级力量发展
> → 封建关系仍然保持，民族资本主义未成为主要经济形式。

这一过程包含两个方面：一方面，原有封建社会发生变化；另一方面，封建剥削关系并未被彻底消除，中国没有由此发展成为独立的资本主义国家。

“半封建”的判断必须落实到经济基础和生产关系，不能只根据文化风气的变化作出解释。

### 5. 民族资本主义发展的限制

民族资本主义受到资本帝国主义的压迫和本国封建势力的束缚。它虽有所发展，但力量弱小，与外国资本及国内封建势力存在复杂联系，未能成为社会经济的主要形式。

**资本主义因素出现，不等于整个社会已经成为资本主义社会。**

## 五、半殖民地半封建社会的六个基本特征

### 1. 六个特征

| 序号 | 基本特征 | 关键词 |
| --- | --- | --- |
| 1 | 资本帝国主义逐步操纵中国的财政、经济命脉和政治，成为支配中国的决定性力量 | 外来控制 |
| 2 | 本国封建势力同外国侵略势力相勾结，成为压迫中国人民的社会基础和支柱 | 内外勾结 |
| 3 | 自然经济遭到破坏，但封建地主土地所有制及对农民的剥削仍然保持，并与其他剥削形式结合 | 旧关系仍在 |
| 4 | 民族资本主义有所发展，但发展缓慢、力量软弱，未成为社会经济的主要形式 | 新力量弱小 |
| 5 | 各地区经济、政治、文化发展极不平衡，地方割据等现象突出 | 发展不平衡 |
| 6 | 人民受到帝国主义、封建主义等压迫，生活困苦，广大农民处境尤其困难 | 人民受压迫 |

### 2. 六个特征的内在联系

| 分析层次 | 对应特征 | 核心内容 |
| --- | --- | --- |
| 统治与控制力量 | 第 1、2 条 | 外来侵略势力与本国封建势力相互勾结 |
| 经济结构 | 第 3、4 条 | 旧关系顽固，新力量弱小 |
| 发展状况 | 第 5 条 | 各地区发展极不平衡 |
| 人民处境 | 第 6 条 | 广大人民承受压迫和贫困 |

记忆线索：**外来控制、封建勾结；旧制仍存、新资弱小；发展不均、人民困苦。**

这些层次相互联系，不能机械切割。外来控制既涉及政治，也涉及经济；分析顺序也不意味着上层建筑单向决定经济基础。

### 3. 与革命任务、革命道路的联系

| 国情特点 | 对应认识 |
| --- | --- |
| 帝国主义与封建势力相互勾结 | 反帝与反封建任务紧密关联 |
| 广大农民受压迫，具有改变处境的要求 | 革命必须重视农民与农村的群众基础 |
| 各地区发展不平衡，统治力量分布不均 | 革命力量可在统治相对薄弱的地区发展 |
| 民族资产阶级受到压迫，同时具有软弱性和妥协性 | 需要具体分析和处理同盟关系 |

这些联系构成理解农村革命根据地、农村包围城市等道路的部分国情依据。革命道路的形成与发展，还需要结合党的领导、群众基础和武装斗争等条件理解。

## 六、阶级关系变化与统一战线

### 1. 近代中国的阶级关系

| 阶级或群体 | 变化与处境 | 理解重点 |
| --- | --- | --- |
| 地主阶级 | 部分地主进入城市经营工商业；地主与商人、官僚等群体之间可能相互转化 | 结合经济地位和现实利益分析 |
| 农民阶级 | 部分农民破产，失去或缺少土地；部分成为产业工人的来源 | 人数多、受压迫深，是重要群众基础 |
| 工人阶级 | 随近代工业发展而成长，集中劳动有利于组织和联系，受到多重压迫 | 理解其组织性、革命性及领导作用 |
| 官僚买办资产阶级 | 与政治特权、外国资本及封建势力联系紧密 | 不能与民族资产阶级混同 |
| 民族资产阶级 | 受到帝国主义和封建势力压迫，自身力量较弱，又同这些势力存在联系 | 革命性与软弱性、妥协性并存 |

### 2. 主力军、领导力量与领导核心

在新民主主义革命的理论框架中：

- **农民是主力军。**
- **无产阶级是领导力量。**
- **中国共产党是领导核心。**

三种表述说明不同的作用，不能相互替代。人数多不自动等于能够发挥领导作用，人数相对少也不能成为否定领导作用的理由。

### 3. 民族资产阶级的两面性

| 方面 | 形成原因 | 政治表现 |
| --- | --- | --- |
| 革命性 | 受到帝国主义和封建势力压迫，经济发展受到限制 | 具有反帝反封建的要求 |
| 软弱性、妥协性 | 经济力量较弱，与外国资本及国内封建势力存在联系 | 在一定条件下容易动摇、妥协 |

民族资产阶级既不是始终彻底革命，也不是完全没有革命性。应当结合历史阶段和具体条件判断其政治态度。

### 4. 统一战线与阶级分析

阶级分析需要考察各阶级的经济地位、利益要求及其相互关系，进而辨别革命对象、依靠力量和可以争取的同盟力量。

统一战线的重要作用在于团结可以团结的力量、扩大革命力量，并处理不同阶级之间的关系。

**统一战线、武装斗争、党的建设，是新民主主义革命的三大法宝。**

## 七、近代中国的主要矛盾

### 1. 两对主要矛盾

| 主要矛盾 | 性质 | 联系的任务 |
| --- | --- | --- |
| 帝国主义和中华民族的矛盾 | 民族矛盾 | 反对帝国主义侵略，争取民族独立 |
| 封建主义和人民大众的矛盾 | 阶级矛盾 | 反对封建压迫，争取人民解放 |

**帝国主义和中华民族的矛盾，是近代中国各种矛盾中最主要的矛盾。**

不同历史时期、具体条件下，矛盾的地位及表现会变化，不能把整体判断理解为每个阶段都完全相同。

### 2. 两对矛盾的联系

帝国主义通过本国封建势力加强统治，本国封建势力又依靠外来力量维持地位，因此反帝与反封建相互联系，民族独立与人民解放相互关联。

地主与农民的对立是封建主义和人民大众矛盾的重要体现，但不能代替后者的完整含义。

### 3. 矛盾概念辨析

| 概念 | 含义与区别 |
| --- | --- |
| 社会基本矛盾 | 生产力与生产关系、经济基础与上层建筑的矛盾 |
| 某一历史时期的社会主要矛盾 | 在特定历史条件下处于主要地位的社会矛盾 |
| 主要矛盾与次要矛盾 | 在多个矛盾之间区分主导地位，不能仅按出现先后判断 |
| 内部矛盾与外部矛盾 | 相对于特定对象及其边界所作的区分，不能直接等同于主次划分 |
| 矛盾的主要方面 | 同一个矛盾中处于支配地位、起主导作用的一方，不等同于“主要矛盾” |

### 4. 近代与新时代的社会主要矛盾

| 时期 | 对应表述 |
| --- | --- |
| 近代中国 | 帝国主义和中华民族、封建主义和人民大众的矛盾 |
| 中国特色社会主义新时代 | 人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾 |

新时代的表述见[党的十九大报告](https://gzw.beijing.gov.cn/gzdj/xxyd/sjdbg/)。两者体现了根据不同历史条件分析具体问题的方法，不能跨时期混用。

## 八、依法治国与以德治国

**坚持依法治国和以德治国相结合。**

| 方面 | 发挥作用的主要方式 |
| --- | --- |
| 法律 | 通过制度规范和国家强制力发挥作用 |
| 道德 | 通过价值引导、行为评价和社会认同发挥作用 |
| 二者关系 | 相互配合，共同服务于社会治理 |

古代存在律法，不等于已经具备现代意义的法治。以德治国也不意味着道德评价可以替代法律程序。参考：[全面推进依法治国](https://www.12371.cn/2019/08/01/ARTI1564615298016193.shtml)。
