### 重点搭配补充

- **prioritize A over B**：记清优先的是A。
- **account for his failure**：可表示“解释他的失败”，也可表示“是他失败的原因”。例如：He could not account for his failure. 他无法解释自己为什么失败。Lack of preparation accounted for his failure. 准备不足是他失败的原因。
- **underlie his failure**：构成他失败的深层原因。underlie 为及物动词，后面直接接宾语，不加 for。

后两项为此前词汇疑问的复习补充，underlie 不在原稿手写词表中。

用法依据：[American Heritage prioritize](https://www.ahdictionary.com/word/search.html?q=prioritize) 将其解释为按重要性排序或优先看待；[Merriam-Webster account for](https://www.merriam-webster.com/dictionary/account%20for) 分列“解释”“构成原因”和“占比”等义项。[Merriam-Webster observe](https://www.merriam-webster.com/dictionary/observe) 收录“遵守”义，适用于本篇 ethical guidelines 的语境。

### 易混关系补充

| 结构 | 方向 | 例子与翻译 |
|---|---|---|
| B results from A | 结果 → 原因 | The delay resulted from bad weather. 延误是恶劣天气造成的。 |
| A brings about B | 原因 → 结果 | The policy brought about change. 这项政策带来了变化。 |
| A contributes to B | 因素 → 结果 | Good communication contributes to trust. 良好的沟通有助于建立信任。 |
| A serves as B | 功能或身份 | These codes serve as guidelines. 这些准则起指导作用。 |
| A refers to B | 指代或含义 | “It” refers to the organization. it 指这个组织。 |

上述例句为补充。特别区分 result **from** 与 contribute **to** 的逻辑方向。

## 阅读理解方法

### 总体步骤

1. **略读短文，把握方向。** 留意每段第一句，初步判断文章在谈什么。
2. **分析判断，确定答案。** 根据题型寻找证据，再对比选项。

### 五类题型

| 题型 | 课堂记录的抓手 | 落实方法 |
|---|---|---|
| 细节题 | 定位＋同义替换＋逻辑词 | 找到原文对应句，核对意思是否一致，注意因果、转折和条件关系 |
| 主旨题 | 首尾段＋段首句＋高频词 | 汇总全文反复讨论的对象与观点，避免用一个例子代替全文主旨 |
| 词义题 | 定义、举例、对比、因果；结合上下文理解未知词 | “未知词”是推断对象；定义、例子及逻辑关系才是线索。把候选意思代回句子检查 |
| 推理题 | 根据文中依据，进一步推断（含义整理） | 依据原文作有限推断，不能脱离文章过度推演 |
| 态度题 | 评价词＋转折词 | 判断作者对具体对象的评价，注意转折后是否调整立场 |

**主旨题常见关键词：** main idea（中心思想）、best title（最佳标题）、purpose（目的）、conclusion（结论）。其中 purpose 和 conclusion 的具体问法仍需结合题干，不能一概套成标题题。

**题干常见动词：** infer（推断）、imply（暗示）、indicate（表明）。补充：infer 强调读者作推断，imply 强调原文或作者暗含某种意思；indicate 也可能对应明确写出的信息，不能仅凭这个词就判定为推理题。

**程度与超出范围的表达：** excessively 是副词，表示“过度地”；exceed 是及物动词，表示“超过、超出”，例如 exceed the limit（超出限度）。注意原文程度与选项程度是否一致。

### 干扰项识别

| 干扰方式 | 含义与检查方法 |
|---|---|
| 偷换概念 | 看似沿用原词，却改变讨论对象、范围或关系 |
| 以偏概全 | 把部分人的情况或一个例子扩大到全部 |
| 无中生有 | 选项提出原文没有的信息 |
| 过度推断 | 从原文出发，但结论超出证据能够支持的范围 |
| 绝对化 | 把有条件、有程度的表述变成“一定、全部、从不”等绝对断言 |
| 张冠李戴 | 把甲的观点、特点或行为移到乙身上 |

### 红色边注与待核对处

细节题旁可辨认出“原文一致”“原文改写”，以及“原文一般—特……”的提示；中间一行疑似“变换措辞”，末行括号字迹不清，暂不补写。可确认这些边注围绕原句与选项的表达对应关系。

推理行可以确认“文中依据”和“走一步”，中间一字仍不够清楚；此前读作“先走一步”，本次不将该字视为确定识别，表中按含义整理。细节题边注首行括号疑似“P1”，未据此指定某道题的答案。

## 作者态度词

作者态度词均为红笔书写；只将带勾的五项标为重点。表内词义按态度判断语境整理。

| 单词 | 中文释义 | 辨析提醒 |
|---|---|---|
| ✓**critical** | 批判的；持批评态度的 | 在态度题中常取此义；critical issue 中可指“关键的” |
| disappointed | 失望的 | 表示期望未得到满足 |
| encouraging | 鼓舞人心的；令人有信心的 | 不是 encouraged“受到鼓舞的” |
| enthusiastic | 热情的；热衷的 | 可表示积极支持或很感兴趣 |
| hateful | 充满仇恨的；可憎的、令人憎恶的 | 原稿记“厌恶的”；需分清“表达仇恨”与“令人憎恶”两个方向，不能简单等同“作者不喜欢” |
| subjective | 主观的 | 与 objective 相对，不等于 pessimistic“悲观的” |
| complimentary | 赞美的；表示赞赏的 | 补充：别与 complementary“互补的”混淆 |
| ✓**objective** | 客观的 | 强调根据事实进行评价 |
| optimistic | 乐观的 | 对结果、前景抱有希望 |
| passionate | 热情的；充满激情的 | 表示强烈情感，本身未必限定为支持某个对象 |
| ✓**passive** | 被动的；消极不主动的 | 不等于 pessimistic“悲观的” |
| ✓**pessimistic** | 悲观的 | 对前景持负面预期 |
| indifferent | 漠不关心的 | 不等于 objective“客观的” |
| ✓**supportive** | 支持的；赞同的 | 补充：be supportive of ... 支持…… |

**补充辨析：** objective / subjective 比较评价依据；optimistic / pessimistic 比较对前景的预期；supportive / critical 比较对对象的态度。它们不属于同一条简单的“好—坏”尺度。

hateful 的两个意义参见 [Merriam-Webster hateful](https://www.merriam-webster.com/dictionary/hateful)。判断态度时，应先确定作者评价的是谁或什么，再看措辞的方向与强度。
