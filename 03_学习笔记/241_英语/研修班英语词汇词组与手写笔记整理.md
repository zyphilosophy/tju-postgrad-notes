## 一 构词法与前缀

### 构词法的基本思路

来源：第 1 页页首手写。

| 构成部分 | 记忆要点 | 例子 |
|---|---|---|
| 词根 | 【手写】承载基本词义 | `dict` 与“说”有关：predict、contradict。 |
| 前缀 | 【手写】改变或限定词义 | happy → unhappy；write → rewrite。例子为【补充】。 |
| 后缀 | 【手写】提示词性 | 【补充】employ → employee；quick → quicken。 |

【补充】这是辅助猜词的方法，不能仅凭词头、词尾确定所有词的含义或词性。词根词缀有变形，很多词还包含历史构词成分；最终须回到整词和语境。

### 否定与错误

来源：第 1 页左上。

| 前缀 | 基本含义 | 课件例词与释义 |
|---|---|---|
| dis- | 不；相反；除去 | dishonest 不诚实的；dislike 不喜欢；disease 疾病；dismiss 解雇、解散。 |
| in- 及 il-、im-、ir- 等变体 | 不，非 | incapable 无能力的；impossible 不可能的；illegal 非法的；irregular 不规则的；immoral 不道德的。原课件另列 ig-，未给例词。 |
| non- | 非，不 | nonsense 胡说、无意义的话；non-stop 不停的；nonverbal 非言语的；nonfiction 非虚构作品。 |
| un- | 不；与……相反 | unable 不能的；unemployment 失业；unavailable 无法获得的、没空的。 |
| mal- | 坏；不良 | malfunction 故障、失灵；maltreat 虐待。 |
| mis- | 错误地；不当地 | mistake 错误；mislead 误导；misinformation 错误信息；misconduct 不当行为。 |

【手写】`ease` 为名词，`easy` 为形容词；`dismiss` 旁补了“解散”和 `fire`（解雇）；`misconduct` 被圈出，标注“错误行为／行为不端”。【补充】`ease` 也可作动词“减轻、缓解”；学 `disease` 时记整词“疾病”，不要直接译成“不容易”。

### 反向动作与相反关系

来源：第 1 页右上。

| 前缀 | 基本含义 | 例词与释义 |
|---|---|---|
| de- | 除去；向下；逆向等 | defend 防御；detach 分离、拆下；deform 使变形。原课件另列 destruct，见下方说明。 |
| dis- | 解除；分开 | disarm 解除武装；disconnect 断开；discharge 释放、排出、准许出院。 |
| un- | 撤销原动作 | unload 卸货；uncover 揭开、发现。 |
| anti- | 反对；抵抗 | anti-racial（保留课件例词，按反对类前缀识记）；anti-foreign 排外的、反外国的。 |
| contra-、contro- | 相反；对立 | contradiction 矛盾、反驳；controversy 争议。 |
| counter- | 反向；对抗 | counter-reaction 反作用、反应；countermeasure 对策、应对措施。 |

【手写】`attach` 与 `detach` 对照；`arm` 武装与 `disarm` 解除武装对照；`countermeasure` 注为“反制措施”。页边还写有 `fend`、`struct`、`form`、`dict` 等构词线索。

【校正】这一组不是“加上前缀就机械取反”的统一规则。例如 `defend` 应直接记作“防御”。表达一般的“破坏、摧毁”优先记 `destroy`；课件中的 `destruct` 不宜作为日常核心用词。记词根时可联想【补充】`struct` 建造、`form` 形状，但不要把所有例词都硬拆成独立英文单词。

### 空间位置与方向

来源：第 1 页中间两栏。

| 前缀 | 方向或含义 | 课件例词与释义 |
|---|---|---|
| circum-、circu- | 周围；环绕 | circumstance 情况、环境；circuit 电路、环路；circulation 循环、流通。 |
| de- | 向下 | descend 下降；degrade 降低等级、贬低、降解。 |
| ex- | 向外 | exit 出口、退出；expand 扩大；export 出口；exclude 排除。 |
| inter- | 在……之间；相互 | international 国际的；interaction 相互作用、互动；interview 面试、采访；interface 界面、接口。 |
| sub- | 在下面 | subway 地铁；submarine 潜艇、海底的；subordinate 下属、下级的。 |
| super-、sur- | 在上面 | superficial 表面的、肤浅的；surface 表面；superstructure 上层建筑。 |
| trans- | 跨越；转移；转变 | translate 翻译；transform 改变、转化；transmit 传送、传播；transfer 转移、调动、转账。 |
| under- | 在下面 | underline 在……下面画线、强调；underground 地下的；underwater 水下的；underlie 构成……的基础、是……的根本原因。 |
| pro- | 向前 | progress 进步、进展；proceed 继续进行、前进；project 项目、投射。 |

【手写】`export / import` 出口／进口；`include / exclude` 包括／排除；`subordinate` 下属；`superstructure` 上层建筑；`project`：n. 项目，v. 投影。`trans-`、`pro-` 旁有重点标记。

【手写】页边另有 `order`、`superpower`、`supernatural`，其中 `supernatural` 注为“超自然的”；`mit` 旁写有发送、发射的含义。`underlie` 旁注“支持”，【校正】读文章时更常按“构成基础／是根本原因”理解，例如【补充】`the causes underlying a problem` 问题背后的根本原因。

### 时间与顺序

来源：第 1 页下方两栏。

| 前缀 | 含义 | 例词与释义 |
|---|---|---|
| ante- | 在前 | antecedent 前事、先行词；anticipate 预料、预期。 |
| ex- | 前任的；以前的 | ex-president 前总统；ex-husband 前夫。 |
| fore- | 预先；在前 | forecast 预测、预报；foretell 预言；foresee 预见。 |
| post- | 在后 | postwar 战后的。 |
| pre- | 预先；在前 | predict 预测；prehistory 史前时期；preface 前言、序言。 |
| re- | 再次；重新；返回 | retell 复述；rewrite 重写；replace 替换、放回；review 复习、审查、评述。 |

【手写】`anticipate` 预期；`forecast / foresee` 预测、预见；`retell / rewrite / replace` 重述、重写、替代；页边可辨认 `review meeting`，下方注“评审会”。

【校正】原课件将 `ante-、anti-` 一起列为“先前”。`anticipate` 中的历史构词形式与 `ante-` 有关，但不能由此把常见的 `anti-` 都记成“在前”；一般先掌握 `anti-` 表“反对”。参见 [Merriam-Webster 的 anticipate 词源](https://www.merriam-webster.com/dictionary/anticipate)。

### 程度高低与超过

来源：第 2 页上方两栏。

| 前缀 | 含义 | 例词与释义 |
|---|---|---|
| by- | 附属的；次要的 | byproduct 副产品、附带结果；课件另列 by-work“副业”，复习优先掌握 byproduct。 |
| hyper- | 过度；极度 | hypersonic 高超声速的；hypertension 高血压。 |
| out- | 超过；胜过 | outdo 胜过、做得比……好。 |
| over- | 过度；过量 | overwork 工作过度、使劳累过度；oversleep 睡过头。 |
| sub- | 次级；下位 | subordinate 下属、下级的；subtitle 副标题、字幕。 |
| super-、sur- | 超过；超常 | superpower 超级大国、超能力；surplus 过剩、盈余；surpass 超过。课件另写 super-nature；手写补充 supernatural 超自然的。 |
| under- | 不足；低于 | underproduction 生产不足；underachieve 表现未达应有水平；underestimate 低估；understate 轻描淡写、把……说得不充分。 |

【手写重点】

| 对照 | 区别 |
|---|---|
| work overtime / overwork | `work overtime` 加班；`overwork` 工作过度。加班强调超出正常工时，工作过度强调负担过重。 |
| overstate / understate | 夸大／轻描淡写。注意描述或陈述的程度。 |
| 【补充】overestimate / underestimate | 高估／低估。注意估计或判断的程度。 |

【校正】课件把 `hypersonic` 注为“超声波”，不宜照背；常见义是“高超声速的”。“超声的”通常为 `ultrasonic`。参见 [Cambridge 的 hypersonic](https://dictionary.cambridge.org/us/dictionary/english/hypersonic)。

### 共同关系与数量

来源：第 2 页左中。

| 前缀 | 含义 | 例词与释义 |
|---|---|---|
| com-、con-、co- | 共同；一起 | company 公司、陪伴；connect 连接；coexist 共存；co-operate / cooperate 合作；colleague 同事；collaborate 合作；coordinate 协调；corporation 公司、法人团体。 |
| mono-、uni- | 单一；一个 | monotone 单调的声音或语调；monopoly 垄断；uniform 制服、统一的。课件写作 mon-，此处规范记为 mono-。 |
| multi-、poly- | 多；许多 | multiple 多个的、多重的；multinational 跨国的、跨国公司；polymer 聚合物。 |

【手写】`company` 陪伴；`corporation` 公司；`coordinate` v. 协调；`monopoly` 垄断；`multinational` 跨国公司。`coexist` 与合作类词汇附近有中文批注，较拥挤，按各词本义区分“共存”和“合作”。

### 特殊意义与专业构词成分

来源：第 2 页右中、左下。

| 构词成分 | 含义 | 例词与释义 |
|---|---|---|
| auto- | 自己；自主；自动 | automobile 汽车；autobiography 自传；autonomous 自主的、自治的。 |
| bene- | 好；有益 | benefit 好处、益处；使受益。 |
| mal- | 坏；不良 | maltreatment 虐待。 |
| macro- | 大；宏观 | macro-economics / macroeconomics 宏观经济学。 |
| micro- | 小；微观 | microscope 显微镜。 |
| aud-、audi- | 听 | audience 听众、观众；audible 听得见的。 |
| bio- | 生命；生物 | biography 传记；biology 生物学；antibiotic 抗生素。 |
| geo- | 地球；土地 | geography 地理。课件写 ge-，此处规范记为 geo-。 |
| phon- | 声音 | phonograph 留声机。 |
| tele- | 远距离 | television 电视；telework 远程工作；telecommute 远程办公；telecommunication 电信、远距离通信。 |

【手写】`auto-` 自己；`autobiography` 自传；`benefit` 利益；`microscope` 显微镜；`telework / telecommute` 远程办公；另补 `telescope` 望远镜，`bio` 生物与 `graph` 书写的构词线索。

【补充】`autobiography = auto + bio + graph + y` 可联想为“自己写自己的人生”；`biography` 是传记。课件将 aud、bio 等列在“术语的前缀”下，复习时统称“构词成分”即可，不必强行把它们都当成普通前缀。

## 二 后缀与词根

### 表示人的名词后缀

来源：第 2 页右下。

| 后缀 | 记忆含义 | 例词与释义 |
|---|---|---|
| -ant、-ent | 从事某事的人 | merchant 商人；agent 代理人；servant 仆人、服务人员。 |
| -arian | 某类人；某种主张或生活方式的实践者 | humanitarian 人道主义者；vegetarian 素食者。 |
| -crat | 某种政治制度或统治形式相关的人 | democrat 民主主义者；bureaucrat 官僚。 |
| -ee | 常表示动作接受者 | employee 雇员。不要认为所有 -ee 词都严格符合此规则。 |
| -eer | 从事某项工作或活动的人 | engineer 工程师；volunteer 志愿者。 |

【手写】`civil / public servant` 公务员、公职人员；`bureaucrat` 官僚；`employee` 工人、员工；`engineer` 工程师。【补充】`employer` 雇主，与 `employee` 雇员对照记忆。

### 抽象名词后缀

来源：第 3 页左上。

| 后缀 | 课件例词与释义 |
|---|---|
| -acy | accuracy 准确性；diplomacy 外交。 |
| -age | courage 勇气；storage 储存、存储空间；marriage 婚姻。 |
| -al | refusal 拒绝；arrival 到达；survival 生存、存活。 |
| -ance、-ence | endurance 耐力、忍耐力；diligence 勤奋；obedience 服从。 |
| -ancy、-ency | frequency 频率；urgency 紧迫性；efficiency 效率。 |

【手写】`survival` 生存、幸存，对应 `survive`；`diligence` 旁注近似“敬业”，规范释义为“勤奋”；`urgency` 紧迫性；`efficiency` 效率。`obedience` 右侧另有一处英文，疑似想写 `intelligence`，字形不完整，不作为确定转录。

【补充】可连成词族：`survive → survival`；`diligent → diligence`；`urgent → urgency`；`efficient → efficiency`。`-al` 也常见于形容词，不能只看词尾判断词性。

### 表示细小的词尾

来源：第 3 页右上。

| 课件列出的词尾 | 例词 | 中文义 |
|---|---|---|
| -cle | particle | 粒子、微粒 |
| -cule | molecule | 分子 |
| -el | parcel | 包裹 |
| -en | chicken；maiden | 鸡、小鸡；少女 |
| -let | booklet | 小册子【手写】 |

【校正】这些主要是课件的词形或历史构词归类，不能据此认定任何以 `-en`、`-el` 结尾的词都表示“小”。初学优先掌握清楚的 `book → booklet`，其余例词记整词词义。

### 动词后缀与词尾

来源：第 3 页左中。

| 后缀或词尾 | 课件例词与释义 |
|---|---|
| -ize、-ise | modernize 使现代化；organize 组织；stabilize 使稳定；realize 意识到、实现。 |
| -en | quicken 加快；weaken 削弱；soften 使柔软、缓和；harden 使变硬。 |
| -fy | beautify 美化；purify 净化；intensify 加强、加剧；simplify 简化。 |
| -ish | finish 完成；abolish 废除；diminish 减少、减弱；establish 建立。 |
| -ate | separate 分开；operate 操作、运转；indicate 表明、指出。 |

【手写】`realize` 实现；`quicken / weaken / soften / harden` 加快／削弱／软化／硬化；`purify` 净化；`abolish` 废除；`diminish` 减少；`establish` 建立；`indicate` 表明。

【补充】`-ish` 在本表中是这些动词的词尾归类，不能推广为“看到 -ish 就是动词”；例如【补充】`childish` 是形容词。`separate` 还可作形容词“单独的”，仍需结合句法辨词性。

### 常见词根

| cide | 杀 | suicide 自杀；herbicide 除草剂；pesticide 杀虫剂、农药。 |

| cred | 相信 | credibility 可信度；credit 信用、学分、功劳；credible 可信的。 |
| dict | 说 | predict 预测；contradict 反驳、与……矛盾。 |
| duct、duc | 引导 | conduct 引导、实施、行为；induce 引起、诱导。 |
| gen | 产生；起源 | generate 产生；genetic 遗传的。 |

### 参考答案与考点

图片未提供标准答案；下表根据句意与常见搭配给出参考。注明其他选项也可成立的题，不应当作严格的单一答案题来背。

| 题号 | 参考选择 | 考点与句意 |
|---|---|---|
| N1 | D. responsibility | `accept responsibility for` 承担……的责任。他承担了政府报告中错误的责任。`duty` 更偏职责、义务。 |
| N2 | 倾向 D. pace；A 也可成立 | `keep pace with` 跟上……的发展。句意为：他们一边塑造未来技术，一边面临跟上最新进展的挑战。`keep step with` 也可表示跟上发展，见下方歧义说明。 |
| N3 | B. range | `the range of the gun` 枪的射程。`area` 面积、地区；`field` 领域；`context` 上下文。 |
| N4 | A. access | `access to information` 获得信息的机会或途径。互联网使人们更容易获取各种信息。原句冠词不自然，见下方校正。 |
| N5 | B. species | `belong to a species` 属于某个物种。`species` 单复数同形。其他分类词较宽泛，动物分类语境优先选 species。 |
| N6 | D. decline | `the decline of an industry` 行业的衰退。去年经济危机中，汽车工业的衰退十分明显。 |
| N7 | A. circumstances | `in / under no circumstances` 在任何情况下都不。否定短语置于句首，引起部分倒装：`should you do`。 |

| V1 | D. substitute | `substitute A for B` 用 A 代替 B：用塑料代替金属。别把替换方向记反。 |
| V2 | C. make out | 辨认出、看清。没戴眼镜，几乎看不清信里写了什么。 |
| V3 | A. contribute | `contribute to good health` 有助于健康；`contribute to` 后也可以接负面结果，不总是“做贡献”。 |
| V4 | C. confirm | `confirm the time` 确认时间。`conform to` 才是遵守、符合。 |

| A3 | B. predictable | 局势不断变化，结果并不总是可以预测。favorable 有利的；dependable 可靠的；reasonable 合理的。 |
| A4 | C. available | 所需大学信息可以在网站上获取。sufficient / adequate 足够的；efficient 高效的。 |

### 原题的用法与歧义说明

**N2：keep pace with 与 keep step with。** 两者都可以表示跟上某种发展。根据课件常见考点推测，题目想考 `keep pace with`，但不能据此把 A 判为英语用法错误。[Collins 的 keep step](https://www.collinsdictionary.com/dictionary/english/keep-step) 也列出它与发展速度保持一致的用法。

**N4：access 的冠词。** 本句表示“获取信息的机会”，`access` 通常按不可数名词使用。可将原句规范为【校正句】`The Internet gives people easier access to all kinds of information.` 不把原句的 `an easier access` 当作背诵范例。

**V5：run the risk 与 face the risk。** C 是惯用短语考查的优先选择；B 表示“面临生病的风险”，在本句也说得通。两者含义有侧重，但不足以让原题形成唯一答案。[Collins 的 face a risk](https://www.collinsdictionary.com/us/dictionary/english/face-a-risk) 提供了相应搭配及例句。

**A4：网站信息。** 课件使用 `at our website`；自己写作时可记【补充】`The information is available on our website.` 网站上可以查到这些信息。
