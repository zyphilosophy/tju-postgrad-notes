# 完形课堂重点词汇与衍生词 纯整理版

对应 P1 员工投入度、P3 工作满意度、P4 组织文化。按词义、词族和搭配整理课堂记录；题目定位另见[词汇与完形对应文档](<02_词汇与P1P3P4对应_纯整理版.md>)。

**标记规则：** ★黄色高亮为课堂重点，○浅红高亮为圈注词；高亮不代表正确答案。【补】为拓展内容，【校】为易错提醒。P1-01 等为词汇组编号，具体题号见配套对应文档。

## 重点词语速查

| 标记词语 | 复习重点 |
|---|---|
| ★**providing / provided that** | 只要、假如，条件从句；见语法补充 |
| ★**retain** / ★**maintain** | retain v. 保留、留住；maintain v. 维持、保持 |
| ★**be likely to** | 很可能做某事；be more likely to do 更可能做 |
| ★**engaged employees** | 投入工作的员工、有敬业精神的员工 |
| in favor of / ★**in terms of** / on behalf of / on top of | 支持／在……方面／代表／在……之上、除……之外；be on top of sth. 还可指掌控、处理得当 |
| ★**job satisfaction** / job security / job opportunities | 工作满意度／工作保障、稳定性／工作机会 |
| instead of / rather than / other than / ★**more than** | instead of 代替、而不是；rather than 而不是；other than 除……以外；more than 多于、不只是、非常 |
| agree with / ○**align with** | 认同；与……一致、使……一致 |
| ★**loyal** / loyalty | loyal adj. 忠诚的；loyalty n. 忠诚 |
| ○**that** | 在 Studies show that ... / I believe that ... 中引导宾语从句 |
| defend against / ★**depart from** | 抵御、防卫／离开、偏离 |
| ★**carry out** / ★**carry on** / ★**set up** | carry out 执行、开展；carry on 继续；set up 建立、设立 |
| introduce / ★**solve a problem** | introduce v. 引入、推行、介绍；solve a problem 解决问题 |
| modify / purify / beautify / ★**specify** | modify 修改；purify 净化；beautify 美化；specify 明确说明、具体指出 |
| ★**consequently** / ★**as a result** | 因此、结果是，表示因果结果 |
| ★**define** / definition | define v. 定义、界定；definition n. 定义 |
| ★**A refers to B** | A指的是B；refer to 也可表示提及、查阅 |

## 词汇与衍生词整理

### P1 员工投入度

| 编号 | 词语 | 释义与核心搭配 | 同源词和课堂联想及校正 |
|---|---|---|---|
| P1-01 | recruit / recruitment | recruit v. 招聘、招募，n. 新成员；recruitment n. 招聘、招募 | 词族记忆：recruit 是动词或名词，recruitment 是名词 |
| P1-02 | be key / central / vital / critical / essential / fundamental to | 对……关键、核心、至关重要、必不可少或根本；to 后接名词或动名词 | 【补】be key to ensuring ...；be critical to 对……至关重要，不同于 be critical of 批评……；这些词也有其他介词搭配，不是只能接 to |
| P1-03 | ensure | v. 确保；ensure sth. / ensure that ...；make sure (that) ... | 【补】assure sb. that ... 向某人保证；insure 为……投保 |
| P1-04 | for instance / for example | 例如，用来引出具体事例 | 本页例证：员工不喜欢变革，但充分沟通能争取支持 |
| P1-05 | addictive / addiction | addictive adj. 使人上瘾的；addiction n. 瘾、沉迷 | 【补】addicted adj. 上瘾的；be addicted to sth./doing；addiction to sth.。不要把 addictive to 当成人“沉迷于”的标准搭配 |
| P1-06 | rewarding | adj. 值得做的、有回报的、令人满足的 | 【补】reward n./v. 回报、奖励；与 award 授奖比较 |
| P1-07 | lay out / lie out | lay out 说明、安排、铺开；本文指把原因与益处说清楚 | 【校】lie out 不是此处目标搭配。lay–laid–laid 放置；lie–lay–lain 躺；lie–lied–lied 撒谎 |
| P1-08 | shift / move / transition | 转变、转移；from A to B 从A转到B | shift v./n. 转移；move v./n. 移动；transition n./v. 转变；【补】a transition from A to B |
| P1-09 | revolve / involve / solve | revolve v. 旋转、围绕；involve v. 涉及、包含；solve v. 解决 | revolve around ... 围绕……；involve doing sth. 涉及做某事；solve a problem 解决问题【搭配补全】 |
| P1-10 | buy into | 认同、接受并支持某种想法或计划 | buy v. 买；buy into change 支持变革，属于熟词的引申义 |
| P1-11 | rarely / hardly / barely | rarely 很少，强调频率；hardly 几乎不；barely 仅仅、勉强、几乎没有 | 【校】三者不能一律译成“几乎不”；都可带否定倾向，但语义不同 |
| P1-12 | obey / follow | v. 服从、遵守；obey orders / follow orders | 【补】obedience n. 服从；obedient adj. 顺从的 |
| P1-13 | productive / productivity | productive adj. 富有成效的；productivity n. 生产率、工作效率 | 【补】produce v. 生产；product n. 产品；production n. 生产 |
| P1-14 | once / unless / otherwise | once 一旦；unless 除非；otherwise 否则 | once 也可指一次：once a month 每月一次 |
| P1-15 | financial / fiscal / finance | financial adj. 财务的、金融的；fiscal adj. 财政的、税收的；finance n. 财务、金融，v. 提供资金 | 【校】fiscal 不宜笼统记为“金钱”；本文 fiscal reward 按上下文指金钱奖励，主动表达宜用 financial/monetary reward |
| P1-16 | award / feedback / response / respond to / incentives | award n./v. 奖项、授奖；feedback n. 反馈；response n. 回应；respond to 回应；incentive n. 激励因素 | 【补】response to ... 对……的回应；financial incentives 金钱激励；reward 强调回报，award 常指正式奖项 |
| P1-17 | resent / review / regard | resent v. 怨恨、反感；review v./n. 审查、回顾、评审；regard v. 看待 | regard A as B 把A看作B；【补】resent doing sth. 对做某事感到不满；resentment n. 怨恨 |
| P1-18 | ★**retain** / ★**maintain** | retain v. 保留、留住；maintain v. 维持、保持 | retain employees 留住员工；maintain morale 维持士气【搭配补充】；【补】retention n. 保留；maintenance n. 维护 |
| P1-19 | morale | n. 士气 | 【补】moral adj. 道德的，n. 寓意；morality n. 道德；不要与 morale 混淆 |
| P1-20 | a long way to go / pace | a long way to go 尚有很长的路要走；pace n. 步速、节奏 | 【校】本文是 go a long way towards doing 对……大有帮助，不能替换成 a long way to go |
| P1-21 | instill / ethos / deliver | instill v. 逐渐灌输、培养；ethos n. 群体精神、组织理念；deliver v. 实现、产生本文所需结果 | 【校】ethos 不是“自我”；deliver 在本文近似 produce，其他语境还可为递送、发表 |
| P1-22 | a sense of humor / a sense of pride | 幽默感／自豪感；sense n. 感觉、意识 | 【补】proud adj. 自豪的；be proud of |
| P1-23 | pay check / minimum / maximum | pay check n. 工资支票；minimum n./adj. 最小量、最低限度；maximum 最大量、最高限度 | 【补】paycheck 也可合写；the bare minimum 最低限度，见P3 |
| P1-24 | run out / use up / check in / sum up / pick up | run out 用完；use up 用尽；check in 登记入住；sum up 总结；pick up 领取、接人、捡起等 | 【校】sth. runs out；sb. runs out of sth.；sb. uses sth. up。本文 pick up 是“领取”，不是“接某人” |
| P1-25 | empower | v. 授权；使有能力、自主权 | empower sb. to do；be empowered to do；AI-empowered AI赋能的（课堂联想）；【补】empowerment n. 授权、赋能 |
| P1-26 | enlarge / enhance / enable / widen / harden / broaden | enlarge 扩大；enhance 提升；enable 使能够；widen 加宽；harden 变硬、使变硬；broaden 拓宽 | 【补】enable sb. to do；broad adj. 宽广的，P4有 broadly；这些是使动意义与构词联想，并非都能机械拆成同一词缀 |
| P1-27 | shape | v. 塑造、影响、决定方向；n. 形状 | shape the direction of ... 塑造……的方向 |
| P1-28 | ★**be likely to** | 很可能做某事；be more likely to do 更可能做 | 同一结构在P1、P3、P4反复出现；后接动词原形，不接名词 |
| P1-29 | ★**engaged employees** | 投入工作的员工、有敬业精神的员工 | 后补：engage v. 参与、使投入；engagement n. 投入度；disengaged adj. 不投入的、疏离的。本文语境不译“订婚的员工” |

| P4-07 | implement / resistance / rejection / refusal | implement v. 实施；resistance n. 抵抗、阻力；rejection/refusal n. 拒绝 | implement ≈ carry out；【补】resist v. 抵抗；reject/refuse v. 拒绝；meet with resistance 遇到阻力 |
| P4-08 | innocent / inconsistent with / indifferent to | innocent adj. 无辜的；inconsistent with 与……不一致；indifferent to 对……漠不关心 | 【补】consistent with 与……一致；innocence n. 无辜；indifference n. 冷漠 |
| P4-09 | invisible / in line with / align with | invisible adj. 看不见的；in line with 与……一致；align with 与……一致、协调 | 【补】visible adj. 可见的；visibility n. 可见度；in line with 与 inconsistent with 形成反义对照 |
| P4-10 | with respect to / with regard to / in contact with | 关于／关于／与……有联系 | 与P3第11题 with regard to 复现；【补】keep in contact with 与……保持联系 |
| P4-11 | unlike / dislike / alike | unlike prep. 与……不同；dislike v./n. 不喜欢；alike adj./adv. 相似、同样地 | 【补】likely adj. 可能的；be likely to do；The two plans are alike 两个计划相似 |
| P4-12 | introduce / ★**solve a problem** | introduce v. 引入、推行、介绍；solve a problem 解决问题 | 【校】problem 为可数名词，记 solve a problem 或 solve problems；【补】introduction n. 引入、介绍 |
| P4-13 | modify / purify / beautify / ★**specify** | modify 修改；purify 净化；beautify 美化；specify 明确说明、具体指出 | 【补】modification 修改；pure 纯的；beauty 美；specific 具体的；specification 规格、详细说明 |
| P4-14 | replace / eliminate / absorb | replace 替换；eliminate 消除；absorb 吸收、理解并内化 | replace A with B 用B替换A；【补】replacement 替换；elimination 消除；absorption 吸收 |
| P4-15 | on-boarding | n. 入职引导、使新员工融入组织的过程；也写 onboarding | 【补】不仅是登记入职，还包括熟悉工作与组织文化 |
| P4-16 | ★**consequently** / ★**as a result** | 因此、结果是，表示因果结果 | 【补】consequence n. 结果、后果；as a result of + n./doing 由于……；与 as a result 区分 |
| P4-17 | influx / actually | influx n. 大量涌入；actually adv. 实际上、事实上 | 【校】influx 为名词 n.；an influx of new employees 新员工的大量涌入 |
| P4-18 | umbrella culture / broadly | umbrella culture 总体文化、统领性文化；broadly adv. 大体上、广泛地 | 与 broaden 拓宽关联；【补】broad adj. 宽广的；broadly speaking 大体而言 |
| P4-19 | ★**define** / definition | define v. 定义、界定；definition n. 定义 | 【补】define A as B 把A定义为B；definition of ... ……的定义 |
| P4-20 | ★**A refers to B** | A指的是B；refer to 也可表示提及、查阅 | 【补】reference n. 提及、参考；refers 是主语A为单数时的形式 |
| P4-21 | subsidiary / emerge / appear | subsidiary adj. 附属的、次级的；emerge v. 出现、形成；appear v. 出现 | 【补】subsidiary n. 子公司；emergence n. 出现；本文 subsidiary cultures 是子文化，不限定为子公司的文化 |
| P4-22 | subjective / objective / negative / positive / active | 主观的／客观的／消极的、负面的／积极的、正面的／活跃的、主动的 | 【补】subjectively、objectively、negatively、positively、actively 为副词；positive attitude 积极态度，active participation 主动参与 |
| P4-23 | context / facet / aspect | context n. 背景、语境；facet/aspect n. 方面 | in the context of ... 在……背景下；facet ≈ aspect；【补】relevance 相关性；more ... than ... 比较结构 |

## 语法与解题补充

### 名词单复数与意义

以下词语常以复数形式出现，但应区分具体意义，不能一概认为没有单数形式。

| 词语 | 释义 | 用法提醒 |
|---|---|---|
| savings | 储蓄、存款 | 此义常用复数；a saving 可指一项节省 |
| earnings | 收入、工资所得；企业收益 | 不能简单等同每个语境中的 salary |
| belongings | 个人财物 | 此义用复数 |
| surroundings | 周围环境 | 与某人或某物周围的环境有关，通常用复数 |
| fundamentals | 基本原理、基础知识 | 常以复数集合表达；fundamental 也可作形容词“基本的” |
| means | 方法、手段；财力 | 方法义单复数同形：a means / several means；不能归成“只有复数” |
| valuables | 贵重物品 | valuable 作形容词表示贵重的、有价值的 |
| convenience / conveniences | 便利／便利设施 | convenient adj. 方便的【补】 |
| humanity / humanities | 人类、人性、仁慈／人文学科 | humanities 不能按“许多人类”理解 |
| necessity / necessities | 必要性／必需品 | necessary adj. 必要的【补】 |
| ruin / ruins | 毁坏、毁灭／废墟、遗址 | ruin 还可作动词“毁坏” |

means 的方法义单复数同形、财力义通常用复数，参见 [Cambridge means](https://dictionary.cambridge.org/dictionary/english/means)；fundamentals 的“基本原理”义参见 [Cambridge fundamentals](https://dictionary.cambridge.org/us/dictionary/english/fundamentals)。

### 成对连接与比较

| 结构 | 规范表达和含义 | 对完形的帮助 |
|---|---|---|
| both ... and ... | 两者都…… | P3：both increases and other monetary incentives |
| either ... or ... | 要么……要么…… | 识别并列选择 |
| neither ... nor ... | 既不……也不…… | 【校】neither 与 nor 配对，不与 or 配对 |
| one ... the other ... | 一个……另一个…… | 限定两个对象时使用 |
| as ... as ... | 与……一样…… | P3：just as effective 同样有效 |
| 比较级 + than | 比……更…… | P4第19题 more ... than ... |
| preferable to / prefer A to B | 比……更可取／比起B更喜欢A | to 为介词；prefer doing A to doing B【补】 |
| the more ... the more ... | 越……越…… | 两个 the 引导联动比较 |
| more B than A | 与其说A，不如说B | 比较两种描述，更符合B |
| ★**more than** | 多于；不只是；非常 | 看后接内容：more than ten 超过十；more than a job 不只是一份工作；more than happy 非常高兴 |

### 非谓语与名词性从句

非谓语动词包括不定式、动名词、分词，以及分词作定语、状语、补语、插入成分的用法。学习时先找主句谓语，再看其他动词形式与谁形成逻辑关系。

| 语法项目 | 课堂记录及规范 | 三篇中的例子 |
|---|---|---|
| 动名词作主语 | doing ... is ... | P3：Providing tangible proof ... is still very important |
| 介词后用 doing | of / to 等介词后接名词或动名词 | P1：part of ensuring ...；P3：In addition to being fair |
| 分词后置修饰 | 主动常用现在分词，被动常用过去分词 | P1：people working within it；P3：those surveyed ... |
| 不定式表目的或修饰名词 | to do 不能一律视作同一种成分 | P3：tasks to perform；P4：To gain an understanding ... |
| 宾语从句 | show/believe + that + 完整陈述 | P3第16题：Studies show that ... |
| 同位语从句 | 解释 fact / idea / concept / news / evidence 等名词的具体内容 | P3：proof ... that their efforts are recognized |
| 主语从句 | it 可以作形式主语 | P1：It is essential that ...；P3：It is crucial that ... |
| 表语从句 | be 后说明主语是什么、怎么样 | P3：Another major contributor ... is how the employee feels ... |

【补】essential/crucial 等表示必要性时，that 从句可用“主语 + (should) + 动词原形”。P3 的 `be performance driven` 要分开理解：**be 用原形**来自表示必要性的虚拟语气；**driven 用过去分词**表示“受绩效驱动、以绩效为依据”。不能把这两个语法理由混为一谈。

### 时间原因目的条件与让步

| 类型 | 表达 | 规范与含义 |
|---|---|---|
| 时间 | when, as, while, as soon as, before, after, since, till, until | 当……；随着……；一……就……；前、后、自从、直到；as/while 需结合上下文判义 |
| 紧接发生 | the moment, the instant | 一……就…… |
| 紧接发生 | no sooner ... than；hardly/scarcely ... when | 刚……就……；【补】句首倒装示例：No sooner had he arrived than ... |
| 原因 | because, since, as, for | 因为、既然；【校】for 可引出解释原因的并列分句，不宜全部归为从属连词 |
| 原因或依据 | seeing that, now that, in that, considering that, given that | 鉴于、既然、因为；in that 常解释某一特定方面的原因 |
| 目的 | so that, in order that | 为了、以便；so that 也可能表示结果，视语境判断 |
| 防止不希望的事 | lest, in case, for fear that | 以免、以防、唯恐；in case 更侧重预防某种可能情况 |
| 目的 | for the purpose that | 【校】主动写作优先用 for the purpose of doing 或 in order that，不机械记忆非典型表达 |
| 条件 | if, unless, as/so long as, only if | 如果、除非、只要、只有……才…… |
| 条件 | ★**providing / provided that** | 假如、只要；条件从句常用表达 |
| 假设与条件 | suppose (that), on condition that | 假设；条件是……；【补】supposing (that) 也常见 |
| in case / in case of | 规范记 in case + 从句；in case of + 名词 | 不把“以防”与 if“如果”无条件互换，不机械添加 that |
| 让步 | though, although, even if, even though, as, while | 尽管、即使；as 表让步时常有特殊语序；while 还可表时间或对比 |
| 强调句 | It is/was + 被强调部分 + that/who ... | 【补】不能把所有 It is ... that 都判成强调句 |

in case 表预先防备，与普通 if 条件结构区别，参见 [Cambridge In case (of)](https://dictionary.cambridge.org/grammar/british-grammar/in-case-of.)。

### 完形答题方法

完形判断包括词汇辨析、语法结构、语篇理解。按以下顺序落实：

1. **重视首句，把握主题。** P1 看员工投入，P3 看工作满意度，P4 看组织文化。
2. **扫读全文，寻找线索。** 注意同词或同源复现，例如 productive/productivity、satisfaction、culture。
3. **瞻前顾后，先易后难。** 先做固定搭配明确的题，再处理需跨句逻辑的题；最后把答案代回全文。

## 易错用法辨析

| 易错记法 | 整理后应记 |
|---|---|
| ethos 自我 | ethos 为群体精神、组织理念；“自我”常用 self/ego，不能混记 |
| a long way to go 对应P1第17题 | 原文是 go a long way towards doing 对……大有帮助；前者是尚有很长的路要走 |
| run out = use up | 含义相关，结构不同：money runs out；use up money；run out of money |
| rewarding = 金钱回报 | 还可指工作本身令人满足、有价值 |
| on top of = 控制 | be on top of a situation 可指掌控局面；on top of 也表示在上方、除此之外 |
| instead of / rather than / other than 都是“而不是” | other than 常为“除……外”；看结构与语境 |
| in contrast / on the contrary 都可互换 | 前者对比；后者常反驳或纠正前面的说法 |
| above all = 总之 | above all 最重要的是；to sum up / in a word / in conclusion 才常表示总结 |
| influx v. | influx 是名词：an influx of ... |
| organization culture | 在本篇按原文记 organizational culture；corporate culture 也可表达企业文化 |
| solve problem | solve a problem / solve problems |
| employement / employerment 一类拼写 | employment；另记 employer 雇主、employee 雇员 |
| means 只有复数；neither ... or | means 方法义单复数同形；neither ... nor |
| issuing bank 泛译为“发行机构语境中的银行” | 按对象区分：银行卡的发卡行；信用证的开证行 |
| behave v. 行为 | 动词译“行事、表现”；behavior 才是名词“行为” |
| ward off = 远离 | 抵御、防止危险或疾病侵害，不只是保持距离 |
| factor into 与 factor A into B | 前者可指成为影响因素；后者为把A计入B的考虑 |
| be performance driven 的理由 | be 原形来自必要性虚拟语气；driven 过去分词表示受绩效驱动 |
| 近义词可以随意互换 | 多数是语境近义或记忆联想；先学搭配，再判断能否替换 |

ethos 的群体特征义参见 [Cambridge ethos](https://dictionary.cambridge.org/us/dictionary/english/ethos?topic=morality-and-rules-of-behaviour)；on top of 的掌控及叠加义参见 [Cambridge top](https://dictionary.cambridge.org/us/dictionary/english/top)；influx 的名词词性参见 [Oxford influx](https://www.oxfordlearnersdictionaries.com/us/definition/english/influx)。
