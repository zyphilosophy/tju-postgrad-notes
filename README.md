## 放置规则

- 官方大纲、招生通知、科目截图放“00_招生与考试”；保留资料年份。
- 总计划、周计划放“01_备考计划”；旧版移入“历史方案”，当前执行入口以本页为准。
- 原始教材、课件、题册放“02_学习资料”对应科目；自己写的总结放“03_学习笔记”。
- 错题订正、重做记录和周复盘放“04_错题与复盘”，科目内按主题或日期命名。
- 暂时不用的数学二、数学三版本及其他讲义版本放“99_归档”。同名文件不等于内容相同。

笔记建议命名为“主题.md”，例如“极限与连续.md”；复盘建议命名为“2026-10-11_启动段复盘.md”。每份错题记录写清题目来源、错因、正确思路和复习日期。

## Git 与 Git LFS

文档内部使用相对链接，便于仓库移动后继续浏览。.gitignore 已排除 tmp、浏览器输出、系统缓存及未完成的下载；全部 PDF 由 Git LFS 跟踪，Git 提交中保存指针，原文件存储在 LFS 中。四科空目录用 .gitkeep 占位。

截至 2026-09-18，全部 PDF 共 98 份、约 3.28 GiB，包括考试大纲、当前学习资料及归档资料。目录整理保留了所有原文件。迁移前后的路径及原文件校验值保存在本地 tmp/整理记录。

克隆前先安装 Git LFS，并执行以下命令获取仓库和完整资料：

```bash
git lfs install
git clone https://github.com/zyphilosophy/tju-postgrad-notes.git
cd tju-postgrad-notes
git lfs pull
```

.gitattributes 中的 PDF 跟踪规则已随仓库保存；后续新增 PDF 会继续使用 LFS。
