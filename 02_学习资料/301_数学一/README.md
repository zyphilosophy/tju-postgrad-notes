# 数学一资料

当前使用数学一版本及通用讲义，共 23 份 PDF。原始文件名保留，按学习阶段分类。

| 目录 | 内容 | 使用方式 |
|---|---|---|
| 01_零基础 | 零基础通关讲义 | 配合启动阶段，补遗忘的基础知识 |
| 02_基础30讲 | 高数、线代、概率讲义和数学一做题本 | 作为第一轮主资料 |
| 03_核心计算 | 核心计算通关讲义 | 随已学章节练计算 |
| 04_1000题 | 数学一试题、解析及基础/强化做题本 | 按已学知识点选题 |
| 05_强化36讲 | 高数、线代、概率讲义及对应做题本 | 基础掌握后再使用 |
| 06_公式手册 | 数学公式手册 | 查漏与回忆，结合例题理解 |

同一道题的横版、留白版、平板版按使用习惯选一种，不需要重复做。数学二、数学三资料已移到[归档目录](<../../99_归档/README.md>)；另有一份文件大小和校验值均不同的同名高数讲义，保留在归档的“数学讲义其他版本”，未将它作为重复文件删除。

数学视频入口：[用户选定的 B 站课程](https://www.bilibili.com/video/BV19PQBBREK1/)。具体分段和学习节奏见[当前备考计划](<../../01_备考计划/天津大学智能医学工程_9月19日起基础恢复版.md>)。
